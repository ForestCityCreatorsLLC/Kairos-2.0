## Overview
**KAIROS 2.0** is a clean-slate, local-first executive operating system engineered for **Forest City Creators LLC**. KAIROS 2.0 treats your live **Obsidian Canopy Vault** (`C:\Users\igxxg\OneDrive\Documents\FCC Business Docs\Canopy Vault`) as the 100% canonical relational database (`Markdown + YAML Frontmatter + JSON Canvas + Obsidian Bases`).

- **Backend Core, Hermes & MCP**: Python 3.11+, `FastAPI`, `Uvicorn`, `Pydantic v2`, `mcp` (`MCPServer` / `FastMCP` — 18 tools), `watchdog`, `PyYAML`, `SQLite3` (`PRAGMA journal_mode=WAL` + `FTS5` + CPU Episodic Vector Store), `google-genai` (with Google Search grounding & `3.0s` circuit breaker), `requests`
- **Cognitive Voice Sidecar**: Isolated FastAPI + WebSocket microservice (`127.0.0.1:8421`) with Dual-Prosody TTS (`Kokoro-82M` ONNX + `gemini-3.8-flash-lite-tts` `[mutter]` `1.12x`/`-3.3 dB` & `[normal]` WAV DSP), `TrainOfThoughtVerbalizer`, `AdaptiveVADController` (`0.50`/`0.35` + `<80ms` barge-in), `WhisperLocalSTTService` (`faster-whisper` `large-v3-turbo`) + `gemini-3.5-transcribe`, and `VisionContextProcessor` (`<45ms` `1080p` WebP)
- **Desktop & Web UI**: `Electron 33` (with `will-attach-webview` sandbox isolation, `persist:kairos-browser` permission deny, external-supervisor awareness, Windows `taskkill /T /F` child-tree cleanup & unlocked audio autoplay), `React 18`, `TypeScript 5`, `Vite 6`, `Tailwind CSS 3`, `lucide-react`
- **Automated Verification**: `pytest`, `httpx` / `TestClient` (98 end-to-end verification tests across Phases 1–15, Checkpoints `v2.0-checkpoint-1` & `v2.0-checkpoint-2`, and Cognitive Voice Batches 1–5)
